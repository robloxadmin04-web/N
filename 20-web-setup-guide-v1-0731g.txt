============================================================
STEP 1 - DALAWANG PALITAN SA config.js
============================================================

Nailagay ko na ang Supabase URL at anon key mo. Dalawa na
lang ang kulang:

  API_BASE_URL
      Ang URL ng Render web service mo. Makukuha mo ito
      pagkatapos mong i deploy. Halimbawa:
      https://dashboard-api-xyz.onrender.com
      WALANG SLASH SA DULO.

  DISCORD_CLIENT_ID
      Discord Developer Portal > ang app mo > OAuth2 >
      Client ID. Mahabang numero ito.

Kung hindi mo pa alam ang API_BASE_URL, i deploy mo muna
ang Render service, tapos balikan mo ang config.js.


============================================================
STEP 2 - SUPABASE AUTH URL CONFIGURATION
============================================================

Ito ang pinaka madalas na dahilan kung bakit hindi gumagana
ang login. Huwag mong laktawan.

Supabase Dashboard > Authentication > URL Configuration

  Site URL:
      https://ang-static-site-mo.onrender.com

  Redirect URLs (idagdag ang dalawang ito):
      https://ang-static-site-mo.onrender.com/**
      http://localhost:3000/**

Ang ** sa dulo ay mahalaga. Iyon ang nagpapahintulot sa
lahat ng page sa ilalim ng site mo.

Kung hindi mo pa alam ang URL ng static site, i deploy mo
muna ito sa STEP 3 tapos balikan mo dito.


============================================================
STEP 3 - RENDER STATIC SITE
============================================================

  New > Static Site
  Repository:            N
  Root Directory:        web
  Build Command:         IWANAN MONG BLANGKO
  Publish Directory:     .

Walang build na kailangan dahil plain HTML lang ito.

Libre ang Static Site at hindi natutulog. Kahit natutulog
ang API mo, mabubuksan pa rin agad ang dashboard.

Kopyahin ang URL na ibibigay sa iyo. Iyon ang ilalagay mo
sa STEP 2 at sa STEP 4.


============================================================
STEP 4 - AYUSIN ANG ALLOWED_ORIGIN SA API
============================================================

Balik ka sa Render web service mo (yung api at bot).
Environment tab, hanapin ang ALLOWED_ORIGIN.

Palitan mo ang * ng eksaktong URL ng static site mo:

  ALLOWED_ORIGIN=https://ang-static-site-mo.onrender.com

WALANG SLASH SA DULO.

Habang * pa ito, gumagana ang lahat pero kahit sinong
website ay pwedeng tumawag sa API mo. Ayusin mo ito bago
ka magpakita sa ibang tao.

Mag restart ang service pagkatapos mong mag save.


============================================================
STEP 5 - TESTING, SUNOD SUNOD
============================================================

1. Buksan ang static site URL mo sa cellphone.
   Dapat lumabas ang login page na may Discord button.

2. Pindutin ang login. Dadalhin ka sa Discord.
   Dapat may nakasulat doon na hihingiin nito ang listahan
   ng mga server mo. Kapag wala iyon, kulang ang scope.

3. Pagkatapos mong pumayag, babalik ka sa dashboard.html.
   Dapat makita mo ang listahan ng server mo.

   Ang may bot na = may Buksan na button.
   Ang wala pa = may Idagdag na button.

4. Pindutin ang Buksan sa server ng tropa mo.
   Dapat mag load ang apat na tab at may laman na
   dropdown ang mga channel at role.

5. Sa Settings tab, buksan ang welcome, pumili ng channel,
   tapos I save. Dapat lumabas ang berdeng Na save na.

6. Sa Premium tab, gumawa ng mapping para sa basic tier,
   tapos idagdag ang sarili mong Discord ID ng 30 araw.
   Maghintay ng mga 5 minuto. Dapat may premium role ka na
   sa Discord.

Kapag umabot ka sa 6 at gumana, kompleto na ang sistema
mula frontend hanggang Discord.


============================================================
MGA MADALAS NA PROBLEMA
============================================================

Blangko ang page, walang lumalabas
  Mali ang config.js. Buksan mo ang browser console.
  Karaniwan ay hindi nabago ang API_BASE_URL.

Hindi maabot ang server
  Natutulog ang API. Hintayin mo ng isang minuto tapos
  refresh. Kung palaging ganito, hindi gumagana ang
  pinger mo sa cron-job.org.

CORS error
  Mali ang ALLOWED_ORIGIN. Dapat eksakto ang URL, walang
  slash sa dulo, at may https.

Walang server na lumalabas pagkatapos mag login
  Kulang ang guilds scope. Mag logout, burahin ang site
  data sa browser, tapos login ulit.

Expired na ang Discord login mo
  Normal ito tuwing ilang araw. Logout at login lang.

You do not manage this server
  Hindi ka admin doon, o hindi mo pa na invite ang bot.

The bot is not in this server yet
  Gamitin ang Idagdag na button sa dashboard.

Missing Permissions kapag nagbibigay ng premium role
  Sa Discord Server Settings > Roles, itaas mo ang role
  ng bot mo. Dapat nasa ibabaw ito ng premium role.
