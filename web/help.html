How to use Helium

Overview

Helium is two pieces working together. This website is where you change things. The bot is what carries them out inside Discord.

YouChange a setting or grant premium on this site.
HeliumStores it, then tells the bot what to do.
DiscordThe role appears, the message posts, the board updates.

Most actions land in a few seconds. Premium role changes made from the website can take up to five minutes, because the bot reconciles memberships on a timer. Anything done with a slash command inside Discord is instant.

What it handles

  • Premium roles that grant and expire on their own
  • Redeem codes so buyers get access without waiting for you
  • Welcome messages and an automatic role for new members
  • Raid protection that screens brand new accounts
  • A status board that edits itself in place
  • Announcements posted as clean embeds

First setup

Five minutes, done once per server.

  1. Sign in with DiscordHelium only asks for your identity and the list of servers you manage. It never reads messages.
  2. Install HeliumOn the servers page, press Install next to the server you want. Servers you already installed show Open instead.
  3. Move the Helium role upServer Settings, then Roles. Drag Helium above every role it will hand out. Skipping this is the single most common reason things silently fail.
  4. Create the role you will sellAny role works. Name it Premium, VIP, whatever fits your server.
  5. Pick your channelsIn Settings, choose where welcome messages, announcements and the status board should go.

Role position

Discord will not let a bot touch a role above itself

If Helium sits below the role it is meant to grant, every attempt fails. The website will still say saved, because the failure happens inside Discord.

Open Server Settings, then Roles, and make the order look like this:

Helium Premium @everyone

Helium above, the roles it manages below. Roles that other bots or integrations created cannot be granted by anyone, so they never appear in the dropdown.

Settings

Welcome message

Posted as an embed in the channel you choose whenever someone joins. Four placeholders are swapped in automatically.

PlaceholderBecomes
{user}A mention that pings the new member
{username}Their name without the ping
{server}Your server name
{count}How many members you now have
Welcome {user}, you are member {count} of {server}.

Auto role

Given to everyone who joins, paying or not. Usually a plain Member role that unlocks the rest of the server.

Do not use your premium role here

Auto role and premium are separate systems. Point them at the same role and every new member becomes premium the moment they join.

Raid protection

Holds accounts younger than the number of days you set. Held members get no welcome message and no auto role, and a line is written to your log channel. Set the minimum age to 0 to accept everyone.

Channels

  • Moderation log quiet notices meant for staff
  • Announcements where posts from the Announce tab go
  • Status board holds one message that Helium keeps editing

Premium

Premium needs two things before a role can ever appear. Miss either one and nothing happens.

1. A mappingWhich Discord role belongs to which tier.
2. A memberWho paid, and until when.

Create the mapping

Premium tab, first card. Type a tier name, pick a role, save. One tier maps to one role. You only do this once unless you add more tiers.

Tier names are free text. basic, vip, lifetime all work, but the spelling must match exactly wherever you use it. VIP and vip are two different tiers.

Grant access

Enter the numeric Discord ID, the tier, and how many days. The role lands within five minutes.

To find someone's ID, turn on Developer Mode in Discord under Settings, Advanced. Then press and hold their name and choose Copy ID. It is a long number, not their username.

What happens next, on its own

  • The role is granted within five minutes of the grant
  • When the expiry date passes, the role is removed
  • If a paid member leaves and rejoins, the role comes straight back
  • Granting again while time remains adds days instead of replacing them

Selling with codes

Codes turn any payment method into an instant role. It does not matter whether the buyer paid by transfer, wallet, or through your own site.

1. Buyer paysAny method you accept. You confirm it yourself.
2. You create a codeOne command in Discord, takes a second.
3. Buyer redeemsThey run one command and the role appears immediately.

Create a code

/premium code days:30 uses:1

Helium replies privately with something like A7K2-9XM4-PQ3R. Only you can see it. Send it to the buyer.

The buyer redeems it

/redeem code:A7K2-9XM4-PQ3R

The reply is private to them, and the role is applied on the spot. No five minute wait.

Things worth knowing

  • A code only works in the server it was created for
  • One person can redeem a given code once
  • Raise uses to make a shared code for a giveaway
  • Redeeming with time left on the clock adds days rather than resetting them
  • /premium codes lists everything still usable

Commands

Every reply is private. Nobody else in the channel sees your codes or anyone's membership.

For members

/redeem code:YOUR-CODE-HERE
/premium status

For staff

These require the Manage Server permission.

/premium code days:30 uses:1 tier:basic
/premium codes
/premium grant user:@member days:30
/premium revoke user:@member
OptionMeaning
daysHow long the membership lasts, 1 to 3650
usesHow many different people can redeem a code, default 1
tierWhich mapping to use, defaults to basic
noteA private label so you remember who a code was for

Status board

One message in your chosen channel that Helium rewrites every time you change an entry. It never posts a second copy, so the channel stays clean and the board can be pinned.

Each entry has a state: Working, Patched, Maintenance or Unknown. The footer counts how many are working out of the total.

If you delete the board message by hand, Helium posts a fresh one the next time something changes.

Announcements

Write a title and a body, press post, and it appears in your announcements channel as an embed within a few seconds. An optional link turns the title into a clickable heading.

Set the announcements channel in Settings first, otherwise the post has nowhere to go.

Troubleshooting

The role never appeared

Work through these in order. It is almost always the first one.

  • Helium is below the role in Server Settings, Roles
  • No mapping exists for that tier yet
  • The tier is spelled differently in the mapping and in the grant
  • The Discord ID belongs to a role, not a person. Role mentions contain an extra &
  • Fewer than five minutes have passed since a website grant

No welcome message

  • The toggle is off, or no channel is selected
  • Raid protection held the account because it is too new
  • Helium cannot see or post in that channel

Slash commands are missing

Close Discord fully and reopen it. Commands register per server when Helium joins, so a client that has been open a long time may not have picked them up.

The site is slow on the first load

The service sleeps when nobody has used it for a while. The first request wakes it, which takes up to a minute. Everything after that is fast.

FAQ

Can Helium read our messages?
No. It never requests message content, and cannot see what anyone types.
Can I use any role for premium?
Any role you created yourself, as long as Helium sits above it. Roles owned by other bots or integrations cannot be granted by anyone and are hidden from the list.
What happens when a membership expires?
The role is removed automatically. Nobody has to remember to do it.
Can one person hold two tiers?
Redeeming a second tier adds that role without removing the first. Revoke before upgrading if you want a clean swap.
Does a code expire if nobody uses it?
No. It stays valid until it hits its use limit or you disable it.
Can I manage more than one server?
Yes. Every server you have Manage Server on appears after you sign in, each with its own settings and members.
